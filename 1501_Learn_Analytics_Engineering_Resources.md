# 1501 Learn --- Analytics Engineering Learning Resources

This document contains a curated set of learning resources for the
10-module Analytics Engineering roadmap.

## Resource Selection Approach

Resources were selected with emphasis on:

-   Official/primary documentation where available
-   Established books and publications
-   Publicly popular YouTube materials with visible engagement signals
-   Practical, real-world GitHub projects
-   Relevance to Analytics Engineering workflows

Recommended learning hierarchy:

1.  **1501 Learn content** --- your own explanations, examples,
    exercises
2.  **Official documentation** --- dbt, Snowflake, Git, PostgreSQL,
    Kimball, GitHub
3.  **Highly validated external material** --- popular YouTube videos,
    books, respected publications
4.  **Real-world projects** --- public GitHub repositories

# Suggested 1501 Learn Lesson Structure

Each module can follow a consistent structure.

## 1. 1501 Learn Lesson

Your own explanation of the topic, written specifically for the learner.

## 2. Recommended Reading

One primary documentation page, article, or book chapter.

## 3. Watch

One selected YouTube video, preferably with strong public engagement.

Display signals such as:

-   Views
-   Likes
-   Channel size
-   Publication date

## 4. Official Documentation

Link directly to the authoritative documentation for the technology or
concept.

## 5. Practice Exercise

A hands-on task the learner must complete.

## 6. Assessment

Short quiz, practical task, or both.

## 7. Mark Complete

Learner completes the lesson after meeting the required criteria.

# Recommended Resource Priority

### Tier 1 --- Official / Primary

-   dbt documentation

-   Kimball Group

-   O'Reilly
-   Wiley

YouTube videos with substantial views, likes, active channels, and
useful learner feedback.

### Tier 4 --- Real-World Projects

GitHub projects that demonstrate complete workflows and can be inspected
by learners.

# Important Note on YouTube Metrics

Views, likes, subscribers, and other engagement numbers are
time-sensitive and can change after this document is created.

The engagement figures in this document represent the public figures
observed during the resource research and should be treated as selection
signals rather than permanent ratings.

For the 1501 Learn LMS, it is useful to store the:

-   Video title
-   URL
-   Channel
-   Date checked
-   Views at time of selection
-   Likes at time of selection
-   Publication date

This makes the resource library easier to maintain as YouTube metrics
change.

# Capstone Outcome

By the end of the programme, the learner should be able to build a
workflow similar to:

``` text
Source Systems
      ↓
Raw Data
      ↓
Cloud Data Warehouse
      ↓
dbt Staging Models
      ↓
dbt Intermediate Models
      ↓
dbt Mart Models
      ↓
Data Tests & Documentation
      ↓
Git / CI/CD
      ↓
Power BI / BI Layer
```

The capstone should demonstrate not just SQL knowledge, but the complete
Analytics Engineering workflow: modelling, transformation, testing,
documentation, version control, deployment, and consumption by a BI
tool.
